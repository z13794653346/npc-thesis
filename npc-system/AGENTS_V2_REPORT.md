# 三NPC Agent受控决策验收报告

验收日期：2026-09-20。对象为对话版本2，不替代论文计划中的正式对照实验。

## 实现边界

- 林掌柜、周衡、沈岚分别从同一会话快照恢复自己的知识、记忆、历史和可用行动；没有跨会话或跨角色的进程全局可变Agent状态。
- 每次自然语言交互只请求一次逻辑模型决策。模型只允许返回`intent`、`evidence_ids`、`action_id`，额外字段、越权事实和越权行动均拒绝且不写入状态。
- 身份、未知信息、事实来源和行动结果都由程序生成。事实正文来自候选记录，行动文本来自实际规则执行结果；模型自由台词不会进入页面或存档。
- 旧存档保留读取，但缺少`dialogue_version=2`时拒绝继续交互。旧自由生成和事实审查代码仅供历史实验脚本使用。

## 真实模型小规模验收

最新有效证据目录：`artifacts/live-agents-20260920T130600-cb30d4/`。

- 模型：`deepseek-flash`；10个逻辑请求，单请求内部暂态HTTP重试上限1次；实际逻辑请求全部成功。
- 三个身份介绍、未知口令、借钥匙、维修、归还、两次领取线索和一次来源回答全部通过。
- 10个原始模型结果均为三字段决策，`reply`字段数量为0；规则兜底次数为0。
- 来源回答只选择`maintenance`，程序输出“转述记录（未核实）；来源：周衡”，没有把转述改写为亲眼见闻。
- 对JSON/JSONL证据执行通用密钥模式扫描，未发现密钥字符串。SQLite存档和本机`.env`不作为可分享附件。

首轮证据`artifacts/live-agents-20260920T130210-ff2f31/`原样保留。首轮所有脚本检查通过，但人工审阅发现来源回答同时选择语义线索和share审计事件，造成重复内容并显示内部角色ID。根因是同一次转述同时写入线索知识和审计事件，而Agent把二者都提升为事实候选。修复后share事件仍保留在存档用于审计，但不再成为第二条可回答事实；定向测试和最新真实复测均通过。

## 结论与限制

V2解决的是“模型自由编造的句子直接成为NPC台词和存档事实”这一工程问题。它不等于消除所有模型误解：模型仍可能在多个合法候选中选择不够相关的事实，场景配置本身也必须由开发者保证正确。本报告中的10次调用仍只属于工程冒烟验收。后续已按独立预注册方案完成216次V2正式合成实验，见[AGENTS_V2_FORMAL_EXPERIMENT_REPORT.md](AGENTS_V2_FORMAL_EXPERIMENT_REPORT.md)；正式结果同样不能外推为普遍零幻觉。
